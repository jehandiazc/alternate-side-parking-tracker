# Images

Drop README screenshots and demo GIFs here (e.g. `dashboard.png`, `demo.gif`),
then reference them from the main `README.md`:

```markdown
![ParkShare dashboard](docs/images/dashboard.png)
```

Tip: dragging an image into a GitHub issue or PR comment uploads it and gives you
a hosted `user-images.githubusercontent.com` URL you can paste directly, if you'd
rather not commit binaries.
